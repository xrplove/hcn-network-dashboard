# Hernandez Coordination Network (HCN)

**Live Cross-Chain Dashboard**

## Overview

HCN is a real-time monitoring and coordination network for cross-chain infrastructure, built on the XRP Ledger ecosystem.

## Quick Start

```bash
# Open in browser
open index.html
```

## Features

- 📊 Real-time network status dashboard
- 🔗 Cross-chain transaction monitoring
- 🏢 Infrastructure node tracking
- 💻 Live system metrics

## Structure

- `index.html` - Main dashboard interface
- `assets/` - CSS, JavaScript, and images
- `data/` - Network configuration and data files
